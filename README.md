# Проект DjangoProject

## Описание:

Проект DjangoProject - это проект по созданию веб-приложения с использованием фреймворка Django.

## Установка:

1. Клонируйте репозиторий:

    ```
    git clone https://github.com/DenisTernovoy/DjangoProject.git
    ```

2. Выберите *Poetry* в качестве интерпретатора.


## Инструкции по работе с проектом

Для запуска сервера необходимо выполнить следующее:
1. Проверьте, что Вы активировали виртуальное окружение в среде разработки.
2. В консоли выполните следующую команду:
    ```
    python manage.py runserver 
    ```
3. Перейдите по ссылке, на котором запустился Ваш сервер. Для этого в консоли найдите строчку:
    ```
    Starting development server at http://127.0.0.1:8000/
    ```
